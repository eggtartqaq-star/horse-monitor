The measurement-layer rebuild of your swing system. Save these into one folder, then run selftest.py before anything else.

Rename after saving. This viewer only accepts a fixed list of file extensions, and .py and .bat are not on it. Each file is offered as .txt, so after saving, delete the trailing .txt — rules.py.txt becomes rules.py.

Windows hides extensions by default. If you cannot see .txt, turn on File name extensions in File Explorer's View tab first.

    Then, in that folder:

    pip install yfinance pandas numpy
    python selftest.py
    python portfolio_sim.py --mode diagnostics

    If the self-test fails, stop — do not run the diagnostic on a broken simulator.
