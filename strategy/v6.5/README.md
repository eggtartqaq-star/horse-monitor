## 跑完之後點睇

按呢個次序睇,唔好倒轉:

1. **最大回撤** — 超過 20% 就係 John 嘅 `drawdown_budget_pct`,系統應該停手。
2. **淨EV vs 毛EV** — 兩者之間嘅差距就係你之前唔知自己喺度畀緊嘅錢。
3. **拒絕紀錄** — 如果「買唔起」同「集中度超標」佔大多數,
   咁問題係戶口太細,唔係策略唔得。呢兩個係完全唔同嘅問題,要分開處理。
4. **集中度** — 頭3隻股貢獻幾多 % 嘅損益。如果超過一半,睇 F-01。
5. **同時持倉分佈** — 如果大部分日子係 0 個倉,你嘅資金大部分時間閒置,
   年化回報會遠低過每筆EV畀你嘅印象。

**最後先睇 Sharpe。** 一個 Sharpe 好睇但最大回撤 40% 嘅系統,你捱唔到。
