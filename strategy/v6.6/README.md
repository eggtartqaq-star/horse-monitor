## 一、第一次安裝(大約 20 分鐘)

1. **放好檔案。** 將成個 `v6.6` 資料夾放喺電腦,例如 `桌面\v6.6`。**舊 V6.4.2 檔案唔好刪。**
2. **裝套件。** 打開 CMD:
   ```cmd
   pip install yfinance pandas numpy requests
   ```
   V6.6 唔再需要 `ta`,但第 4 步對照測試嘅舊引擎仍然要。
3. **自我測試(關卡 V-2):**
   ```cmd
   cd %USERPROFILE%\Desktop\v6.6
   python selftest.py
   ```
   要見到「全部通過」(82 項)。之後喺 `owner_settings.json` 將 `"V2_代碼測試"` 改做 `true`。
4. **對照測試(關卡 V-3):**
   ```cmd
   copy ..\dual_engine_v6_4.py .
   python parity_check.py
   ```
   - **佢測咩:** 用你嘅舊引擎(`ta` 指標 + 原函數)同 V6.6,喺 10 隻股、3 年數據,逐日計兩條路徑嘅訊號。
   - **佢唔測咩:** `daily_strong_signals.py` 個掃描流程本身。嗰部分由 `equivalence_check.py` 同離線掃描測試處理。
   - **過關標準:** 指標差 < 0.01;有訊號日子一致率 ≥ 98%。
   - **過關之後:** 喺 `owner_settings.json` 將 `"V3_對照測試"` 改做 `true`,並將輸出畀 AI 睇。
5. **真實收費(關卡 V-1):** 喺微牛搵一張成交單據(佣金、平台費、SEC/TAF、匯兌),影相畀 AI。
   AI 會填 `owner_settings.json` 嘅 `real_fee`,並跑:
   ```cmd
   python lab.py --mode feecheck --fee-min 每邊最低收費 --fee-bp 每邊bp
   ```
   如果真實收費之下淨 EV ≤ 0(S4),**呢個戶口規模下,用咩上限都唔應該交易。**
6. **戶口:**
   - **金額:** `owner_settings.json` 嘅 `account_hkd` 填你短線戶口**真正**嘅淨值。
   - **孖展:** 你嘅微牛戶口係孖展戶口;如果有負現金 / 欠款,先還清先開新倉(CRO 條件 C-6)。
7. **Telegram token:** 去 @BotFather → `/revoke` → 攞新 token,步驟見第五節。

> **點解設定放喺 `owner_settings.json`:** 改呢個檔**唔會**令規則指紋變。規則指紋只代表代碼同規則。

## 二、每日(收市後,香港時間朝早)

雙擊 **`掃描_v66.bat`**。佢會先自動跑自我測試;唔過關就唔會掃描,並叫你**唔好交易**。

### 睇頂部印章

```
Swing V6.6.2  規則指紋 0b05757d0076  |  ...
交易路徑: bt(回測驗證版)  影子路徑: scan(只記錄)
名義上限: A(10% 一律)  B′ 關  |  每筆風險 1.0%  最多 2 倉
設定: 戶口 HK$10,000  上限 A  B′ 關  關卡 G1/V1/V2/V3 = ✓✗✗✗
```

- **規則指紋唔係 `0b05757d0076`** = 代碼唔係呢個版本 → 先問清楚先好交易。
- **「美股開緊市」警告** = 今日條 bar 未收市;呢次唔會寫入記錄簿,收市後再跑。
- **「下載失敗」列表** = 嗰幾隻今日冇訊號,唔係冇事。
- **「[X] 掃描出錯」** = 今日唔好交易,將錯誤訊息畀 AI 睇。

**每個交易日都要跑一次**,熊市日都要。掃描器每次會寫一行「心跳」去 `ledger/runs.csv`;
記錄交易(fill)嗰陣,系統靠佢判斷訊號係咪「今日有效」。漏跑一日,之前嘅訊號就當過期。

### 四個區

| 區 | 意思 | 點做 |
|---|---|---|
| ① 交易清單 | 回測驗證版訊號,按排名(引擎二先,之後評分);只顯示 A(10%)股數 | 由 #1 開始揀,最多 2 倉(扣返現有持倉) |
| ② 舊掃描器版先有 | 例如引擎二冇突破20日高 | **唔交易**,已自動記錄 |
| ③ 被擋 | 財報、止蝕過闊、10% 上限買唔起 | 學習用 |
| ④ 你嘅持倉 | 由記錄簿讀出,計好今日止蝕位 | 引擎二:止蝕只升不降;**以呢度為準**(TradingView 嗰條線只係近似) |

**落單:**
- 聽日開市落,用**限價單**(CRO C-8)。開市價偏離收市超過 1% → 重計 R值/風險,唔達標就放棄。
- 成交後即刻設**系統計出嚟嘅**止蝕。止蝕唔准自己收緊,永不下移(CRO C-9)。

**落單之後一定要記錄**(唔好用 Excel 改 csv):
```cmd
python ledger_v66.py fill open --ticker PFE --price 27.10 --shares 4 --stop 25.30 --engine E2
python ledger_v66.py fill open --ticker NFLX --price 69.40 --shares 1 --stop 64.92 --target 83.60 --engine E1
python ledger_v66.py fill close --ticker PFE --price 28.40 --reason 移動止損
```

記錄嗰陣會即刻檢查有冇違規(**S2**),以下任何一樣都會標記:
- 已經有 2 倉
- 名義值超上限
- 每筆風險 > 1%
- 冇 live 訊號、或者只係舊掃描器路徑
- 訊號太舊:上次掃描冇呢隻、上次掃描係熊市,或者上次掃描之後漏咗交易日
- 冇掃描記錄(`ledger/runs.csv`)
- 護欄擋咗(例如財報)
- 系統 A 倉位係 0(買唔起)
- 止蝕高過系統止蝕超過 1 仙(自訂收緊)
- 股數多過系統用「你嘅成交價 + 系統止蝕」計出嚟嘅股數

另外,揀咗排名超過空位數嘅訊號會標「留意」(唔算違規,但 review 會列出)。
