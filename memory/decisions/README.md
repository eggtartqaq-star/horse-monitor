# Decision Journal

One file per investment decision, named `YYYY-MM-DD-<ticker>-<action>.md`, created
by 腦大裝草 from `templates/decision-record.md` **before any order ticket is cut**.

Records are append-only: the original thesis, assumptions, dissent, and
pre-registered exit criteria are never rewritten. This journal is the raw material
for `/post-mortem` and the firm's continuous learning loop.
